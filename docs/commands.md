# Aero Befehle

| Befehl | Zweck |
|---|---|
| `aero` | Aero Shell starten |
| `aero update` | Arch und Aero gemeinsam aktualisieren |
| `aero rescue -on` | Rescue-Konsole im laufenden System |
| `aero rescue -full` | vollständige Rescue-Umgebung |
| `search "Begriff"` | Websuche |
| `web URL` | URL öffnen |
| `download URL` | Datei herunterladen |
