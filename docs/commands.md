# Aero Befehle

Die Aero Shell ergänzt normale Linux-Befehle durch kurze, zentrale Aero-Kommandos.

| Befehl | Zweck |
|---|---|
| `aero` | Aero Shell starten |
| `aero --version` | Aero-Version anzeigen |
| `aero help` | Befehlsübersicht anzeigen |
| `aero status` | Aero- und Systemstatus anzeigen |
| `aero update` | Arch und Aero gemeinsam aktualisieren |
| `aero rescue -on` | Rescue-Konsole im laufenden System |
| `aero rescue -full` | vollständige Rescue-Umgebung |
| `aero search "Begriff"` | Websuche öffnen |
| `aero web URL` | URL öffnen |
| `aero download URL` | Datei herunterladen |

## Grundprinzip

Normale Linux-Befehle bleiben verfügbar. Aero stellt darüber eine einheitliche Kommandoebene bereit, die später um Datei-, Netzwerk-, Git-, Programm- und Systemfunktionen erweitert wird.
