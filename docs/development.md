# Radon OS Entwicklung

Radon OS wird ab jetzt vollständig auf **Linux Mint** entwickelt.

Die Entwicklungs-VM soll Linux Mint verwenden. Ein Windows-Shared-Ordner darf ausschließlich zum Dateitransfer zwischen Host und VM verwendet werden. Er gehört nicht in die Quellstruktur oder finale ISO.

Entwicklungsreihenfolge:

1. Radon Shell und Mint-Basis
2. Radon Base und zentrale Konfiguration
3. Desktop / HUD
4. Boot und Rescue
5. Paket- und ISO-Build
6. Installer
7. optionale Anwendungen
8. VM-Test
9. Hardware-Test
