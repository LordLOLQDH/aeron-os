# Radon OS Versionierung

Radon OS verwendet eine eigene Versionsnummer unabhängig von der Linux-Mint-Version.

Aktueller Entwicklungsstand:

```text
RADON OS 0.3.0-dev
```

Die zentrale Quelle ist `VERSION`. Bei relevanten Releases müssen Versionsanzeige, README, Installer, radonfetch und relevante Systemdateien gemeinsam aktualisiert werden.

Die Linux-Mint-Basis wird unabhängig von der Radon-Version aktualisiert.
