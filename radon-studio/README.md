# Radon Studio

Grundgerüst für eine mögliche zentrale Verwaltungs- und Entwicklungsumgebung.

Mögliche Bereiche sind Systemverwaltung, Radon-Einstellungen, Logs, Diagnose und Projektverwaltung. Die App wird nur umgesetzt, wenn diese Funktionen nicht sinnvoller durch vorhandene freie Programme abgedeckt werden.
